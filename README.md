# 🌙 NOT OWRS
**A Psychological Visual Novel**

**Status:** Early Development 🚧  
**Current Release:** Intro Preview

## 📖 About the Project

**NOT OWRS** เป็นโครงงานเกมแนว Visual Novel เชิงจิตวิทยา ที่ได้รับแรงบันดาลใจจากแนวคิดทางพระพุทธศาสนาเรื่อง **“ไม่ใช่ของเรา” (Non-attachment / Anatta)**

โครงงานนี้มุ่งสำรวจความสัมพันธ์ระหว่างมนุษย์ ความยึดติด และการปล่อยวาง ผ่านการเล่าเรื่อง ตัวละคร และประสบการณ์แบบ Interactive Storytelling 

เป้าหมายของผู้พัฒนาคือการนำศิลปะการออกแบบภาพและเทคโนโลยีมาผสมผสานกัน เพื่อสร้างสื่อที่เข้าถึงง่าย และเปิดโอกาสให้ผู้เล่นได้สำรวจความคิด พร้อมทั้งตั้งคำถามกับเรื่องราวและความรู้สึกที่พบเจอภายในเกมผ่านการตัดสินใจของตนเอง
